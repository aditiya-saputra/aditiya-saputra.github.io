Tentang Saya

Saya Aditiya Saputra, siswa di SMQ-MA Umar Bin Abdul Aziz yang tertarik di bidang pemrograman dan multimedia. Sehari-hari saya aktif mengembangkan bot Discord menggunakan Python—salah satunya Mirai Helix untuk server H.E.L.I.X—serta membuat skrip otomasi, eksperimen model bahasa (LLM), dan modifikasi peramban untuk komputer berspesifikasi rendah.

Di samping kode, saya juga mengerjakan proyek animasi 3D, pengeditan video, dan desain grafis.
